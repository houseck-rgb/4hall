[허브에 바로 올리는 법] Netlify Drop (무료, 로그인 불필요)
────────────────────────────────
1. 브라우저에서 https://app.netlify.com/drop 접속
2. 이 폴더 안의 파일 전체(위 목록)를 통째로 화면에
   끌어다 놓기(드래그 앤 드롭)
   * 폴더째로 올리면 자동으로 인식됩니다
3. 몇 초 뒤 https://무작위이름.netlify.app 주소가 생성됩니다
4. 그 주소로 접속하면 화면 하단에 "홈 화면에 앱 설치하기"
   배너가 뜨고, 버튼을 누르면 바로 설치됩니다
5. 어떤 기기에서든 이 https 주소로 접속하면 똑같이 설치할 수
   있습니다 (로컬 파일로는 이게 불가능해서 꼭 필요한 단계입니다)

다른 호스팅(GitHub Pages, Vercel, 회사 서버 등)에 올리실 경우도
이 폴더 안 파일 전체를 그대로, 같은 폴더 구조로 올리면 됩니다.

[링크 주소 넣는 법]
────────────────────────────────
index.html을 텍스트 편집기로 열고, LINKS 배열에서
url: "오픈 체크" 처럼 되어있는 부분에 실제 주소를 넣으세요.

예)
{ key:"open-check", label:"오픈 체크", ... url:"오픈 체크" },
→
{ key:"open-check", label:"오픈 체크", ... url:"https://example.com/open-check" },

http:// 로 시작하지 않으면 클릭해도 이동하지 않습니다(정상).
